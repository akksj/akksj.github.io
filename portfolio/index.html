SwitchKit India

A job-switch kit for Indian developers with 2–6 years of experience: a 30/60/90-day switch plan, resume and LinkedIn guidance, negotiation scripts, notice-period and joining checklists. Includes a free CTC to in-hand salary calculator (FY 2026-27, new tax regime) and long-form articles on expected-CTC answers and notice-period buyouts.

MediQ Clinic

A MERN clinic desk for a neighbourhood doctor. Patients book slots with a clash check, reception checks them in and issues the next token, doctors update only their own appointments, and a waiting-room board refreshes every 10 seconds.

  • MongoDB
  • Express
  • React
  • Node.js
  • JWT

Runs locally · not deployed yet

GitHub ↗

Udhaar Khata

A MERN ledger for a kirana counter: a product catalogue with stock and reorder levels, bills that mix cash and credit, and customer udhaar balances. Stock is checked before a bill saves, failed bills put stock back, and a collection can't exceed what the customer owes.

  • MongoDB
  • Express
  • React
  • Node.js
  • JWT

Runs locally · not deployed yet

GitHub ↗

College Timetable Generator

A PHP and MySQL prototype that builds a class grid and makes sure no teacher or room is booked twice. Includes the SQL schema and an admin login, and now uses mysqli instead of the removed mysql_* API.

  • PHP
  • MySQL
  • HTML
  • CSS
